# 单位转换 Unit Converter

手机上用的单位转换小网页，不用安装，打开就能用。

**网页地址：https://zhushangs.github.io/unit-conversion/**

## 支持的转换

- 🌡️ 温度：°F ↔ °C
- 📏 长度：in ↔ cm
- 🥤 容量：fl oz ↔ ml（可切换美制 / 英制）
- ⚖️ 重量：lb ↔ kg、oz ↔ g

每个标签下都有常用参考表（体温、烤箱温度、一瓶矿泉水、鸡蛋等），点一下就会填入。

## 在 iPhone 上使用

1. 用 Safari 打开上面的网页地址
2. 点底部「分享」→「添加到主屏幕」
3. 以后从主屏幕图标直接打开

## 部署

GitHub Pages：Settings → Pages → Deploy from a branch → `main` / `(root)`。
整个应用就是一个 `index.html`，没有依赖、不需要构建。
